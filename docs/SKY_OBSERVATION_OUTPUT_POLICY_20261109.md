# Sky 資訊輸出政策｜2026-11-09（研究展示草案）
使用者明確要求：即使正式驗證未通過，也要提供**實際取得**的完整可用資訊，由使用者自行判斷是否交易。

## 對所有 Sky 掃描、隔日多空、波段、警戒、六模型研究訊號適用的輸出原則
1. 第一行保留交易結論（例如：🔴 禁止新進場、未驗證通過）；**交易資格與資訊展示分離**。
2. 呈現可查證的股票、價格、成交時間、來源、漲跌、成交量、方向性研究訊號、模型版本、觸發條件、風險、結果與資料不足原因。逐欄標示「已確認／研究未驗證／待確認」。資料缺漏時保留空欄，絕不填假分數、假機率、假價位。
3. 有效時間與範圍：即時、延遲、歷史、局部市場、官方或備援必須清楚區分；未達覆蓋門檻不得叫做「全市場完整即時掃描」。
4. 即使風控 BLOCK、資料 DATA_BLOCKED、研究 HOLD，仍顯示**已存在且有來源**的觀察與缺口；不得偷偷把 BLOCK 改為 PASS、不得因使用者自主判斷就提升正式買進資格。
5. 隔日預測不同於當沖／5日訊號。只有已完成正式資料、模型權重與獨立樣本外校準才可顯示「已校準上漲機率」；其他只能顯示研究分數／未驗證方向。
6. 每個建議附資料時間、失效條件、停損風險、成本與可否計算 RR；資料不足時不得虛構交易規劃。
7. 無論研究候選是否可交易，保留失敗、不符合條件與等待驗證的真實證據；提供觀察資訊不構成自動下單授權。
8. 僅經 W0/P0-G 核准與實際 API、CI、Artifacts、手機 E2E 驗證後，才可將新研究展示接入 Production。
9. 此文件與 `research/sky_observation_only.py` **只新增資訊層**；不更改 Production `src/main.py`、`scan.yml`、P0-R 或 Cloud Run。

## 執行範例
`python -m research.sky_observation_only --input output/latest.json --output output/observation_only.json`

此命令只轉換**既有掃描 artifact**；不能啟動全市場行情查詢，也不能補回被上游捨棄的逐檔資料。下一步由 W3A 按單一檔案責任修復上游觀察保留，再由 W0 核可接線與部署。
