# Sky 純分析模式｜無券商與無模擬交易帳本政策（2026-11-27 修訂）

## 使用者正式選擇：只進行分析，不自動交易

Sky 以讀取官方行情、資料來源驗證、研究觀察、股票多空分析及手機報告為目的；**不要求連接券商、不執行或建議由系統自動送出的委託**。真實持股只有使用者主動提供時才作個人持股分析，且不得公開至 GitHub Issue。

- 使用者可以在沒有券商帳戶、交易紀錄、損益、持倉、停損或模擬帳本的情況下，取得**明確標記資料範圍的研究觀察**；不得把缺少交易狀態當作行情觀察功能的故障。
- 2026-11-21 的 `docs/SKY_PAPER_LEDGER_PERMANENT_REMOVAL_20261121.md` 優先於 2026-11-10 舊文件：**永久禁止**恢復專用模擬交易帳本、模擬委託／成交／持倉／損益事件及其重播、排程與驗收依賴。`#508` 不是結案條件。
- 不產生虛構帳戶、零持倉、零日損、虛擬成交、模擬績效或購買張數；使用者沒有提供的帳戶與交易資訊記為「未提供／不適用於純分析」。
- 不因策略升級、Production、P0-R 真實帳戶資訊或交易資格尚未核准而阻止**可獨立驗證的行情及多空觀察**。對研究輸出標記 `OBSERVATION_ONLY`，對未驗證的進場建議維持 `HOLD / NO_TRADE`。
- 不必展示與使用者未要求的自動交易驗收細節，但必須保留**分析品質**相關限制：資料日期／時區／來源、新鮮度、Fugle A1/A2、K 棒完成性、成交量與 VWAP 真實性、新聞與財報證據、估算費稅滑價、策略風險揭露及成本後 RR。這些不得被刪除或冒稱通過。
- `src/risk_engine.py` 及 P0-R 限制保留作研究風險評估與可選的交易計畫檢查；不要求為了取得行情觀察先填個人持倉、資金或損益。**只有需要給出可執行進場、停損、加碼、建議張數或 Production 策略資格**時才依正式治理進行風控查核，缺資料時不推測。
- Fugle 包月不代表無限流量；保留官方 API 速率限制、來源契約、跨 Workflow 並發保護及同次 Artifact 獨立讀回。不要恢復因按次付費而造成的固定五分鐘跨指令冷卻。
- 真正與純分析無關的舊券商下單或專用模擬帳本元件只有經過相依盤點、研究成果保存與正式 CI 驗收才可 `SAFE_DELETE`，不能刪除共用的資料驗證、成本、風險、測試或證據機制。

## 清楚區分輸出

- `RESEARCH_AVAILABLE`：具備可認證資料時，即可提供行情與多空研究觀察，不要求券商或模擬帳本。
- `INSUFFICIENT_DATA`：標示缺少的資料、可取得的範圍、資料時間與拒絕原因，不補造數值。
- `NO_LIVE_TRADING`：自動下單永久關閉；純分析不需為此啟用券商或委託功能。
- `NO_TRADE / HOLD`：不代表禁止研究分析，而是未通過取得可操作進場建議的資料、策略或研究風險條件。
- `PRODUCTION_PROMOTION_HOLD`：研究級整合成功不等於具有正期望值或已核准正式模型升版。

本政策只精簡研究功能的**前置條件和顯示契約**，不放寬任何真正交易決策的必要成本、風險或行情安全閘門。
