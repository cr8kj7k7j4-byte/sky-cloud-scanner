# Sky 快掃資訊優先規則（2026-11-09）

## 指令與輸出合約

「Sky 快掃」「Sky 全市場即時掃描」要求：
1. 先讀官方 TWSE、TPEx 股票母池，逐股列入全市場觀察輸出。未收到資料的股票仍列出，標示 MISSING_QUOTE。
2. 使用富果付費 TSE、OTC 批量快照，提供取得的價格、漲跌幅、成交量、來源、最後成交時間及資料驗證狀態。未確認的資料必須明確標示 UNVERIFIED_EXECUTION_TIME、STALE_EXECUTION_TIME 或其他錯誤，不能稱為即時成交。
3. 每輪都生成 `output/sky_quickscan_information/full_universe.json` 和 `latest.md`；提供 100 元以下觀察排名、全市場母池／快照／有價格／新鮮成交覆蓋率。
4. 觀察資訊獨立於交易門檻：即使完整成交報價覆蓋率不足，仍輸出已有來源支援的資訊；不把研究評分冒稱驗證勝率、不編造買進價／停損價。
5. **最終結論：🔴 禁止新進場、未驗證通過**，直到正式資料鏈、策略、風控與交易權限實際通過驗證。使用者可自行閱讀資訊與做決策，不代表系統解除禁止交易的治理規則。
6. 不執行下單、不自動升級策略、不刪除任何安全檢查；研究資訊與正式可交易訊號永遠分離。

## 驗收區分

- 母池涵蓋：是否包含當次 TWSE＋TPEx 官方股票清單的每個代號。
- 快照代號涵蓋：批量快照是否含股票代號。
- 可觀察價格涵蓋：是否收到合法價格欄位。
- 新鮮成交驗證覆蓋：逐股真實成交價、交易日、成交時間符合新鮮度要求。
- 正式交易資格：上述資料足夠仍不代表策略已通過風控與成本後正期望。

每一層需獨立列出，禁止互相替代。
