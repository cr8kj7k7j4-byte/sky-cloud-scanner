# P0-K Research Source Policy

## 目的

本文件定義 Sky Cloud Scanner 如何接收公司公告、財報、法說、新聞、產業與政策資料。

## 來源優先序

1. MOPS／主管機關／公司正式公告
2. TWSE／TPEx 官方資料
3. 公司官方投資人關係資料
4. 可信研究資料
5. 可信媒體
6. 社群或二手轉述只作為線索

## 強制規則

- 外部資訊先標準化為 Evidence，再進 Evidence Ledger。
- 每筆 Evidence 必須保留來源名稱、來源類型、發布時間或觀測時間。
- 無法確認來源或時間者，不得成為主要交易依據。
- 新聞利多／利空不是交易訊號。
- 事件分類器只做研究標記，不得直接產生買進、放空、加碼、停損或停利。
- 若官方來源與媒體說法衝突，標記 REVIEW_REQUIRED。
- 若來源讀取失敗，系統必須顯示 NOT_CONNECTED 或 ERROR，不得用模型補寫事實。
- 所有交易仍須通過 P0-C 與 P0-R。
