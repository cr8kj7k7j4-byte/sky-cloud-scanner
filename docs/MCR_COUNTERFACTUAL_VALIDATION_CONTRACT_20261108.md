# MCR｜反證與結果驗證規格（固定基準；不調整 Production）

## 已知資料與禁止事項
- 從官方 TWSE／TPEx 收集的每日融資減少候選，是研究 **observation**，不是已成交交易。
- 個股推估維持率不是實際整戶維持率，不以「低於 130%」假定觸發追繳。
- 現有 2026-11-06 的 520 筆是 **1 個交易日的 520 筆觀察**，不能主張 520 筆獨立交易，也不得推論收益。
- 官方融資資料的可用時間需逐來源驗證。缺少可核對發布／取得時間時，不能將當天收盤視為可成交訊號。
- 不能用同一天的融資餘額和成交量當作當天盤中已知資料；風險、追高、成本與交易單位都須驗證。

## 第一階段：固定證據與研究資料品質
1. 所有 daily ledger 保持不可覆寫；只追加日期資料。
2. 相同股票的連續清洗觀察以 **7 個曆日內延續**定義為同一 episode；這是去重的 **研究帳本規則**，不是已驗證買進門檻。
3. 同日分別觀察減幅、融資規模、官方當日成交股數的分布與缺失率，不以減幅單一欄位排名直接賦予交易資格。
4. 所有單位明確記錄：融資餘額來源單位／官方成交股數 shares；計算比率前確認股、張轉換、特別交易標的與上市櫃欄位口徑。
5. 跨年退市、更名、股票異動、交易日與停牌需作 PIT／存續偏差審查。尚未完成標示失敗或不足。

## 第二階段：價格證據
- 不覆寫已存在的日觀察 ledger。
- 價格證據另行附檔，需有 market、symbol、session、close、source、captured_at、adjusted=false。
- 僅使用 **訊號當日之後**、來源日期與擷取時間可驗證的資料。
- 可先做 1／3／5／10 個交易日 **收盤價參考變動**；不是進場成交價、真實 R 倍數或淨損益。
- 不完整時保持 PENDING_FORWARD_SESSIONS，不能把缺漏當作 0% 報酬。
- 若價格證據缺少完整交易日序列，應暫停相關 horizon 的結果計算。

## 第三階段：事先登錄的 A/B/C/D 對照
- A：相同交易日、交易所、流動性／股價／波動率區間之合理母池。
- B：融資減少代理研究條件。
- C：不使用融資資料的價格反轉規則。
- D：價格反轉 + 融資減少條件。
- 未取得 PIT 母池、價格反轉規則、全部當時已知資料及真正可執行進出場規則，不能比較 A/B/C/D 淨績效，更不能宣稱 D 優於 C。
- 舊日期已供設計參考，不得當成全新樣本外；不調整閾值、權重、Top N 與出場天數美化回測。

## 第四階段：成交與正期望
- 先有可審計的買進觸發、進場時間、真正可成交證據、停損、出場及回報。
- 使用 P0-X 已校準成本來源 `src/cost_profiles.py`、`src/config.py`；假如使用 0.45% 主假設及 0.65% 壓力成本，必須另標示這是跨研究策略的**壓力測試**，非個人券商實際成交淨費率。
- 未驗證價差、滑價、委託成交率、漲跌停與持倉風險時不得申報已證實淨期望。
- P0-R 風控：單筆損失 ≤ 5,000 元、單檔投入 ≤ 100,000 元、最多 3 檔、總風險 ≤ 15,000 元、單日虧損達 10,000 元停止新進場。

## 研究裁定
- 累積 ≥ 200 可評估樣本、≥ 20 真正未來交易日、≥ 2 市場環境、結果完整率 ≥ 95%、單一股票集中度 ≤ 20%，且包含一致的樣本外、Walk-forward、成本後期望值、PF、最大回撤、流動性與前視證據。
- 一天 520 筆 observation，仍是一天，不算 520 次獨立交易。
- 未完成時 `INSUFFICIENT_DATA` 或 `HOLD`；若資料充分而假設失效則 `REJECT` 或 `ARCHIVE`。
- 最終任何 `PROMOTE_CANDIDATE` 須 W0／P0-G 正式審查，研究程式**不修改 Production、不下單**。

## 來源與操作
- 正式規範：`SKY_SYSTEM_REGISTRY_V2_1.md`、`research/RESEARCH_FREEZE_REGISTRY.md`、`docs/SKY_VALIDATION_PROTOCOL_V1_0.md`。
- 稽核產出：`research_output/mcr_event_ledger/YYYY-MM-DD.json`、`research_output/mcr_episode_audit_latest.json`。
- `research/mcr_forward_markouts.py` 接受經獨立驗證的未來 EOD 行情；無價格來源時產出待驗證而不捏造結果。

## 2026-11-08：交易日完整性及結果缺口增補（不改研究假設）
- 只接受已封存的 TWSE／TPEx **雙市場同日官方價格快照**作為 EOD 研究時鐘；不按單一股票有價日期推進持有天數。
- 任意兩個快照間若缺少平日日期，列為 `UNVERIFIED_SESSION_GAP` 並暫停跨越此缺口的結果；不自行猜測國定假日、停市或正常交易日。只有取得獨立可靠的官方休市證據，才能釋出相應缺口。
- 個股在交易日缺報價（含停牌、資料缺漏）列為 `MISSING_REFERENCE_PRICE` 或 `MISSING_PRICE_ON_REQUIRED_SESSION`；不可把下一筆價格往前挪成第 1／3／5／10 日結果。
- `research_output/mcr_evidence_gaps_latest.json` 必須顯示完成的各持有期參考觀察數、交易日時鐘缺口、未來交易日及可執行樣本不足等原因。
- `research_output/mcr_markout_latest.json` 即使有參考漲跌幅，仍禁止推論成交可行性、真實損益、成本後正期望值及升級 Production。
- 週一至週五 18:40（台灣時間）使用既有 GitHub Action；週末沒有新交易日；排程是否定時準點觸發仍須交易日實際執行證明。
- 任何修訂只能改善 **資料與驗證完整性**；不能借機調整已凍結策略假設、門檻、交易報酬目標或出場規則。
