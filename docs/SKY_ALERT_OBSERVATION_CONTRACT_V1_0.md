# Sky 警戒｜即時觀察與正式交易資格分離 V1.0

## 使用者操作規則（2026-11-09）

- `Sky 警戒`、`Sky 即時警戒`、`Sky 全市場警戒`：要求 **上市＋上櫃全市場**，優先輸出截至查詢當下可取得、具有資料日期／成交時間／來源的逐股行情及警戒資訊。
- **無論驗證結果**，均公開已確認的觀察資料、覆蓋率、資料缺口、拒絕原因、研究信號與可取得的技術欄位。缺失數據不得虛構、補齊或當作新成交資料。
- 若市場完整性、風控、觸發或成本驗證未通過，結論顯示：**🔴 禁止新進場、未驗證通過**；仍顯示 `OBSERVATION_ONLY_NOT_PRODUCTION` 的即時觀察候選與原因，不得將其稱為 A+、正式買點或已校準機率。
- 交易決策由使用者自行判斷；系統不得自動下單，也不得因此解除 P0-R、P0-C、P0-G 或資料時效性檢查。
- 不能完成全市場涵蓋時，以已取得的實際數量／母體總數／上市與上櫃分別覆蓋率及失敗原因回報，**不得稱為全市場掃描完成**。
- 盤中掃描 GitHub Actions：`.github/workflows/scan.yml`；掃描原始報告 `output/latest.json`，新增 `alert_observation`（包含最多 100 檔真實已驗證成交的觀察報價）。此集合只供觀察，不參與正式策略訊號、部位、停損或自動交易。
- `Sky 持倉監控` 保持 PMS/持倉查詢路線，不與全市場候選警戒混淆。
