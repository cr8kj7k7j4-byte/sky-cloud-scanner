# Sky 五大模組資料權限與交易規則變更提案（2026-11-03）

**狀態：RESEARCH_BRANCH / REVIEW_REQUIRED / PRODUCTION_UNCHANGED**。富果 ChatGPT 連接器不等於 GitHub FUGLE_API_KEY。不得以可存取清單推定資料品質或可買進。

## 共同前置資料閘門（五模組）
1. 每筆行情要有股票代碼、交易所、資料來源、交易日期、最後成交價及可查證的更新時間；開盤前的 `referencePrice`、`previousClose` 不可顯示為現價。
2. 即時成交缺失、過時、API 未授權、429、欄位異常、官方來源衝突：`WAIT/禁止交易`，不得回填假資料。
3. 成交量、VWAP、價差、五檔和分K只能在來源驗證後使用；多空分數缺必要證據改為「待確認」，不得捏造。
4. P0-R 優先：資金500,000、單筆1R=5,000、單檔上限100,000、最多3檔、組合風險15,000、當日淨損10,000停新倉、連續2筆停損停新倉。分批與整股數量仍受每股風險/資金/剩餘組合風險最嚴限制。
5. 基礎當沖成本使用已校準 USER_CASH_DAYTRADE_20261022；滑價、價差、成交率未驗證前不得聲稱完整成交成本已知。成本後RR最低1.5，優先2.0。未通過不進場；不得為了湊RR修改目標。
6. 不追高、不向下攤平、不放寬停損、不因權限增加就自動下單。A+ 需要全部資料及觸發與風控通過，A=觀察，X=淘汰；無 A+ 應直接回報沒有合格新進場。
7. 研究/封存策略不可藉資料權限、閾值或參數重新升版。所有正式新訊號依研究凍結登錄、PIT/OOS/成本/前瞻/W0-P0-G門檻。

## 模組差異
- **當沖 v1.4 ACTIVE**：做多、當日進出、原則小於100元；官方上市/上櫃母池＋已辨識資料來源，Fugle 深查須在盤中確認成交時間、量、VWAP、多週期、相對強弱與突破品質。P3>P4>P1>P2；P5/P6禁止新倉。短線漲停、急拉、乖離大及壓力太近否決。未證實的新增資料只能加註，不得提升A+。
- **Swing V1.0 ACTIVE**：3–20交易日，獨立日週線、價量、法人、營收/財報及催化；查證公告發佈時間避免回看偏誤。原有未完整可重播規則仍受治理限制；V1.1/5D不得直接替代。
- **融資斷頭反彈 RESEARCH_ONLY**：融資融券餘額不等於維持率低於130%或實際斷頭。必須有合格的市場/券商維持率與事件定義、滯後公告時間、獨立反轉觸發及成本後驗證；資料不全維持HOLD。
- **空方 RESEARCH_ONLY**：`canBelowFlatMarginShortSell` / `canBelowFlatSBLShortSell`僅為交易資格旗標，不保證有券源。另查借券數量、放空成本、限制、獨立偏空結構、回補觸發及停損；沒有正式驗證不產生賣空交易建議。
- **Sky 警戒 CANDIDATE_ALERT**：不得受目前持股限制；富果到價通知10組是富果帳號額度，不是GitHub排程。須明確價格來源、觸發規則、去重、通知送達和失敗警示。股價抵達警戒門檻不等於買進訊號。
