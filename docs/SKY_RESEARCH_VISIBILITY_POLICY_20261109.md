# Sky 研究觀察與交易資格分離｜2026-11-09

使用者要求：所有 Sky 指令仍顯示可核對的觀察資料；正式驗證不足，可在結論標示「🔴 禁止新進場」，不得以交易資格阻斷研究資訊。交易由使用者自行決定，系統不得自動下單。

## 跨模型的建議輸出契約（尚需各模型逐一實作與驗收）

1. **資訊輸出不等於交易許可**：A+/A/X/RESEARCH_ONLY 均可揭露已取得、合法可顯示的個股及原始證據。X 不可從正式禁止交易清單變成可下單。
2. **資料日期、觀察時間、來源分離**：盤後融資、歷史收盤、盤中成交報價各有獨立欄位；不得把報告產生時間寫成報價時間。
3. **不得補造缺值**：現價、融資維持率、VWAP、成交量、買進觸發、最高接受價、停損、分數及成本後 RR 無來源時填 null / 待確認。
4. **所有研究候選都可分頁**：不裁成 Top N，提供觀察原因、拒絕交易原因、完整率和可檢查輸出。
5. **原 P0-R、P0-C、Production、研究升版與未經確認不交易規則不變**；嚴禁虧損加碼、停損放寬及自動下單。
6. **最終動作**只使用既有動作集：買進、等待、觀察、續抱、加碼、減碼、停損、退出、禁止交易；研究觀察單檔使用「觀察」，整體正式交易使用「禁止交易」。
7. **報告須按四種驗收分開**：程式測試、資料完整、掃描產出、交易資格。未逐項驗收不得宣稱即時全市場已可用。
