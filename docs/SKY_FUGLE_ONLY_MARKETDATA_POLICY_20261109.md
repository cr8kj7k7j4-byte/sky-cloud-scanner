# SKY｜富果付費行情唯一來源政策（2026-11-09）

## 使用者要求
所有 Sky 指令與當沖、波段、隔日、融資研究、六模型、手機/ChatGPT 顯示的**市場報價／K 線／成交量／成交時間／量價特徵**優先使用已授權的 Fugle Developer 付費資料。不得在 Fugle 不足時自動改抓 TWSE MIS 或其他免費行情並冒充同一資料品質。

## 目前執行層
- `SKY_FUGLE_ONLY_MARKETDATA=1` 為 Python 行情路由預設；`scan.yml` 也明確設 1。
- `src.quote_provider.collect_market_quotes` 富果資料不達最新成交門檻時，保留來源與缺值、NO_TRADE，不請求免費 MIS 備援。
- `src.diagnose_sources` 停止免費 MIS 診斷抽樣，只查 Fugle 個股／TSE/OTC bulk。
- `src.official.fetch_mis_quotes` 有中央防線，富果專用模式阻止免費 MIS 請求。
- `src.fugle` 提供真實 API 用戶已購買的市場資料；不新增付費服務或暴露密鑰。
- 既有 `research.sky_full_universe_information` 已直接使用 Fugle bulk，對缺失或未驗證成交時間的觀察只列研究資料。

## 統一 Fugle 月訂閱計費前提（2026-11-22，Sky／#363 最新決議）
- **適用範圍**：Sky 正式當沖 v1.4、Swing V1.0、Swing V1.1 研究、日 K／五分鐘 K 棒研究、回測、手機／ChatGPT 橋接、波段／當沖掃描，以及所有合法 Fugle 資料讀取工作流程。這是全系統**成本假設／治理口徑**，不是上述各執行入口均已驗收的證明。
- **已知購買方案**：使用者於 2026-11-22 再次確認 Fugle Developer **NT$1,499／月固定訂閱**。不假設每一次 API 請求會另外計費；不得單憑「可能產生單次額外費用」阻擋已授權且符合配額的研究或行情下載。
- **費用與交易成本分離**：此 NT$1,499 是行情資料的月固定訂閱成本，**不是**每筆買賣的券商手續費、交易稅、滑價或回測成交成本；既有 `src/cost_profiles.py` 與 `src/config.py` 交易成本設定不因本決議修改。
- **實際授權與使用限制**：包月≠無限速或全部端點開通。必須遵守 Fugle 官方方案當下開放的 API 範圍、頻率限制、HTTP 429、金鑰有效性及取得資料的時間範圍；如帳戶權限/限流或執行證據不足，標記待確認，不臆測實際下載或額外費用。
- **防重機制目的**：保留既有跨 Workflow 原子化 claim、快取、可驗證結果讀回、限流、失敗時安全阻擋；其目的為避免無效重工、HTTP 429、競爭條件及資料污染，**不再以按次計費作為必要理由**。不得為了符合包月前提而直接刪除共用安全保護。
- **驗收等級**：本條款只可核准「Fugle 月訂閱成本前提／文件一致性」；不等於確認所有模型實跑成功、全部 API endpoint 授權、持續有效訂閱、跨 Workflow 去重 E2E、歷史資料完整性、實際收益或 Production 研究升版。
- **分工限制**：Claude 負責的 `research/backtest_daily/`、`backtest-daily-brk20.yml` 等研究入口，仍由 Claude 於原工作線維護；W0 僅記錄差異及驗收，不覆寫 Claude 檔案。
- **正式依據**：本 Repo Issue #363（2026-11-22 使用者決議）；官方方案資訊 https://developer.fugle.tw/docs/pricing/ 與 https://developer.fugle.tw/pricing/ 。個人實際帳單/超額費條款未於 GitHub 取得獨立收據，依使用者明確確認採包月前提。

## 官方非行情例外
TWSE/TPEx 官方股票代碼母池、上市上櫃身分、交易日曆與法規制度可作**識別、資料完整率分母、合規驗證**；不得把它們的免費價量當成研究／交易行情來源。GitHub 的研究證據、模型版本與 Workflow 不是行情來源。

## 尚未完成的全系統驗收
這次中央路由與主掃描切換不等於已逐一認證所有其他 repo、研究腳本、外部 App/Cloud Run 或歷史資料來源。需逐個檢查：資料源是否真為 Fugle、API 權限與配額、日期時間、欄位 schema、必要價量特徵、完整 13 欄結果及來源時間。若 Fugle 沒有該指標或權限不足，列 `待確認` 或 `DATA_BLOCKED`，不得私自替代或補造。

## 風控
任何行情或模型尚未驗證，不得自動下單、不放寬 P0-R、不得用延遲收盤價冒充盤中成交，也不得以未驗證研究評分當作勝率。這是資料來源政策，不是策略升版。
