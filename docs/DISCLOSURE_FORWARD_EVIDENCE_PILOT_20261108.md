# 官方公告快照｜前瞻來源證據採集 V1

**用途**：接續研究 Issue #318、PR #320 及富果歷史價格驗收 PR #321，先保留「首次觀測到的官方資料」原始證據。這不是歷史營收公告 `published_at` 修復，也不是正式交易策略。

## 凍結資料契約
1. 來源：上市/上櫃最新月營收彙總與上市/上櫃最新重大訊息，共四個公開 API；每次執行取得原始 HTTP JSON bytes，連結、取樣時間（UTC）、回應 HTTP 狀態、原始位元組大小、SHA256、欄位與筆數。
2. 每來源各有獨立 `*.raw.json` 與單一 `manifest.json`；來源不完整時 `INCOMPLETE_DATA`。缺欄、HTTP 錯誤不得偽造成功。
3. `observed_at_utc` 是下載時**首次觀測**時間，不是交易所原始發布日期；不得把出表日期、營收所屬月份、重大訊息發言時間直接轉成歷史營收公告 `published_at`。
4. 本版未完成獨立逐則原始公告真實性核對、歷史事件唯一 ID、更正/重覆清理、可交易時點及長期持久儲存。正式 `historical_pit_event_count=0`，`production_signal=false`。
5. 此資料來自官方公開端點，但使用／保存應遵守各來源條款，避免存放機敏或非公開的授權資料。本版**不含富果付費原始行情轉存**。
6. CI 為 PR/手動執行，**不新增 cron**；GitHub Actions artifact 僅供有限期限證據，並非可長期不變更的資料倉儲。正式啟用前需先驗證 GCS bucket、服務帳戶 IAM、GitHub OIDC、保留政策、失敗告警與重試、重覆排程及用戶通知。
7. 等正式持久化端到端測試通過再上 GitHub Actions 排程；目前不得宣稱前瞻累積工作已自動上線。
