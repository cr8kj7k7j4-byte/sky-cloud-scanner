# SKY 資訊優先顯示契約 V1.0｜2026-11-09

狀態：**顯示與證據保留之工程候選；不更改 Production Alpha／P0-R／下單權限。**
Owner：W0 審核；W3A 交易資料所有權；W3B 手機顯示所有權。

## 使用者需求

所有 Sky 快掃、當沖、全市場、波段、Swing 5D、單股更新、警戒、六模型與系統健康相關回覆，**應盡量提供來源實際取得的資訊**，即使資料不完整、模型未驗證或買進資格不成立，仍應提供研究與觀察資訊。不得用「暫無合格候選」取代「資料根本不足」的診斷。

## 強制分層

1. **行情證據**：逐檔來源、成交價與成交時間；TWSE、TPEx 分別記錄有效成交數及分母；明確標示上市/上櫃與 MIS OTC 備援。不得以日線收盤、參考價、委買委賣或 stale close 冒充 live last trade。
2. **候選證據**：研究候選與交易合格候選分開；已有資料可列出，但未經完整市場及成本/風控檢查，全部標示「未驗證／觀察」，不可 A+ 或執行買進。
3. **模型證據**：只有真實執行的方向/分數才可呈現；分數不是勝率、未校準概率；權重、版本、run_id、資料時間與來源缺漏應列「待確認」。
4. **交易許可**：所有正式交易決策保留原有資料完整性、成本後 RR、P0-R 部位及停損閘門；缺資料 NO_TRADE，不自動下單。
5. **稽核輸出**：每一輪 scan.yml 無論成功/交易覆蓋閘門失敗都嘗試產出 `output/information_first.json`，上傳至同一 `sky-scan-{run_id}` artifact。原始 `output/latest.json` 不更動，研究報告不取代正式結果。

## 指令與顯示

- `Sky 全市場完整掃描`、`Sky 即時全市場完整掃描` 均映射既有 `all_market` 分析，不宣稱增加未擁有的資料權限。
- 每次回覆先標：🟢可執行／🟡等待或觀察／🔴禁止交易，再說明**資料涵蓋範圍、報價時間、覆蓋率、最後有效執行 Run、資料失敗原因**。
- 已有研究候選就列出股票、來源、方向、價格時間及資料成熟度；現價不是有效盤中逐筆成交則標 `—`，另可明確標示「前收價（非即時）」。
- `A+` 的合法性與買進觸發、最高接受價、停損、加碼及成本後 RR 完全不變；不符合時為等待／觀察／禁止交易。
- 若沒有候選資料，顯示 `候選資料無法確認`，不要說 `全市場零候選`；若掃描完整而確實零合格，才說 `目前沒有符合條件的新進場標的`。
- 只有來源有真正標的時才列出標的；不得合成全市場名單、虛構價格、評分或填補缺漏。

## 驗收條件

- 新指令路由、完整/不足來源、報表不存在、失敗仍保留產物均測試。
- 於實際交易日核查每次掃描的 GitHub `event=schedule`、交易日判定、artifacts、實際逐筆成交時間、TWSE/TPEx 覆蓋率，並檢查手機端登入保護與可讀取性。
- **本 PR 不啟用付費全市場授權**。富果 connector 單股成功不等於 GitHub REST 全市場批次權限成功；未取得實際完整資料前不得稱「即時全市場完整掃描成功」。
- W0/P0-G 核准及 CI、真實交易日 Run、Artifact 讀回之後，才能更新正式部署及使用者手冊狀態。
