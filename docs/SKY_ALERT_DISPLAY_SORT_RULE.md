# Sky 警戒｜Mobile Mode 顯示與排序規則

更新日期：2026-10-28

## 適用範圍
本文件僅規範 `Sky 警戒` 使用者介面輸出排序和展示方式，不變更 Sky Production、P0-C、P0-R、研究分級或任何交易策略。

## 固定排序
1. 每次執行 `Sky 警戒`，先重新取得監控池所有股票的最新可用行情。
2. 依每檔當次評估的「多方評分」**數值由高至低**排序（100 → 0）。
3. 同分時依「空方評分」由低至高；仍同分時依股票代碼由小至大。
4. 評分無法驗證時顯示「待確認」，排在有有效評分的股票之後；不得沿用過時分數假冒即時評分。
5. 警戒項目可於文字結論中優先提醒，但不得擅自改變表格的多方分數降冪排序。
6. 股票觀察名單可能變動；清單應由受控觀察池或連接的追蹤清單決定，不得硬編碼固定股票數。

## 固定十欄（順序不可變）
股票｜現價｜方向｜多方評分｜空方評分｜買進觸發｜最高接受價｜停損／失效｜分類｜現在動作

## 風險與證據
- 多方、空方評分屬市場證據的主觀量尺，不是勝率或統計機率。
- 最新行情標示來源與資料時間，資料不足時註明；不可編造即時價、VWAP、停損、目標或評分。
- 只有滿足資料充足、型態、觸發、追高否決及扣除成本後風險報酬門檻，才可分類 A+。
- 沒有 A+ 時直接顯示「目前沒有符合條件的新進場標的」。
- 未驗證的最高接受價、停損或加碼價應顯示「待確認」，不可為了補齊欄位捏造。
- 任何 UI 排序更新不構成交易策略升版、正期望證據或正式 Production Promotion。

## 驗收案例
給定 4 檔有效多方評分 83、95、83、42，且兩檔 83 的空方分別為 17、25，輸出順序必須為：95、83（空方17）、83（空方25）、42；缺分者置末。
