# Sky 研究資訊可見性與交易資格分離規則 V1.0
生效範圍：本儲存庫研究型掃描報告及統一命令輸出。依 2026-11-09 使用者明確指示。

## 使用者決策權
使用者自行決定是否交易。系統不得隱藏已取得且可標註來源與時間的市場觀察資訊，只因該資料不滿足正式交易門檻；但必須把交易風控結論與研究觀察明確分開。

## 強制顯示
- 每次顯示執行時間、資料成交時間、行情來源、已知延遲、TWSE/TPEx 母池與有效報價數、覆蓋率、掃描執行狀態、候選數、來源警告及失敗原因。
- 全市場閘門未通過時，保留實際觀察到的候選，標示 `PARTIAL_OBSERVED_SUBSET_ONLY`、`🔴 禁止新進場／未驗證通過`、`X／觀察`；不得稱為全市場排名、正式 A+ 買點或已通過正期望驗證。
- 同一股票若有已驗證當日成交價及成交時間，可如實顯示；未驗證只可顯示已知樣本來源與時間，現價欄為「—」，不得把日收盤、備援價或昨天資料冒充即時價。
- 基於不完整母池的相對強弱、研究分數、勝率、觸發價、最高接受價、停損與停利不得臆測；真實可觀察的價量與來源資料可另外附註。
- `Sky 波段現在掃一次` 的 V1.1 研究掃描仍保留獨立資料新鮮度閘門，不得修改凍結的 D-close 買點語義。
- 「程序完成」「資料完整」「候選出現」「正式交易資格」「策略驗證通過」須分列；不自動下單、不升版 Production。

## 涵蓋範圍界線
實際取得部分股票 ≠ 完整市場。分層研究（日線母池＋個股盤中驗證） ≠ 上市＋上櫃全市場即時報價；OTC MIS 僅為備援。所有不足繼續標記 DATA_BLOCKED，不得停用風險或品質閘門來美化顯示。

## 維護
本規則先適用於 Sky Swing/Swing 5D 與 Unified all_market 報告。其它模型、Cloud Run 手機頁面必須分別驗收部署，不能僅因本檔建立就宣稱已全面生效。
