# Sky 資訊呈現與交易資格分離｜V1.0（2026-11-09）

## 使用者授權
使用者自行決定交易與否。所有 Sky 掃描應盡量回報已實際取得且有來源與時間的股票、觀察價量、研究候選、模型結果及風險訊息，不得只因正式市場資料驗證未通過就隱藏觀察資訊。

## 仍須遵守的限制
- 若完整全市場有效成交價或新鮮度 Gate 未通過，結論顯示「🔴 禁止新進場／未驗證通過」，不得把部分樣本稱作全市場即時掃描或 A+ 正式買點。
- 局部候選僅標示 `PARTIAL_SAMPLE_OBSERVATION`，分類 X、動作觀察；可以提供來源及已知資料，但不能強迫填入未驗證的「現價」、多空 0～100 評分、交易觸發、最高接受價、停損、目標價及成本後 RR。
- 必須顯示資料日期、時間與時區、來源、已知延遲、上市與上櫃母池及有效報價、涵蓋率、工作狀態、候選數、被拒原因、研究訊號與資料缺口。
- 報表分開標示程式成功、行情完整、研究候選成立、正式交易資格及策略驗證是否通過。
- 不自動下單；P0-R 風控及 Production 升版治理不可因資訊可見性改動而放寬。
- OTC MIS 備援不等於 TPEx 官方完整即時資料；日收盤大範圍掃描不等於全市場盤中即時報價。

## 範圍與驗收
這是一項顯示政策，需各入口分別接線並透過實際 GitHub Actions artifacts 和手機部署驗收，不因文件已建立就宣稱所有介面全面上線。
