# Sky 全市場研究可見性契約（研究資訊與交易資格分離）

## 使用者指令
- `Sky 全市場完整掃描`: 進入既有盤中掃描工作流，並讀取同一輪的研究觀察輸出。
- `Sky 查詢六模型研究訊號`: 必須同時回報六模型的真實 runner / 權重 / 逐筆訊號是否已驗證，不能把三套規則型研究觀察冒稱六模型。
- `Sky 六模型全市場即時掃描`: 僅當六套 runner 真正存在、同交易日行情與完整性驗證完成，才可聲稱六模型全市場推論完成；否則仍顯示實際取得的研究觀察與缺口。

## 強制顯示（包括禁止新進場時）
1. 首行交易限制可顯示「🔴 禁止新進場、未驗證通過」。資訊顯示不等於下單授權；最終是否採取個人交易行動由使用者自行決定。
2. 必須顯示資料時間、資料來源、上市/上櫃涵蓋、驗證通過筆數與缺漏數量；無證據寫「待確認」，不可寫零。
3. 實際已驗證的逐股成交價可用於研究觀察，即使整體 market gate 未通過；不得把它放入 Production 的候選評分、A+、風控放行或交易建議。
4. 模型可提供獨立且有來源的研究方向、研究分數、條件價位；缺少所需時間序列或模型 runner 證據時，相關欄位為 null/待確認，不虛構。
5. 歷史研究、研究規則與六模型即時推論嚴格區分。AI 分數不等於漲跌機率；未經校準不得顯示「上漲率」。
6. 不修改 P0-R、P0-C、P0-X 風控或正式 Production 閘門，不自動下單，不放寬 stop、資料新鮮度或全市場覆蓋驗證。
7. `output/research_visibility/latest.json` 是同輪讀取產物；`output/latest.json` 的 Production Gate 保持獨立。Workflow 失敗時應檢查 artifacts 與 logs，不把檔案存在當成功。
8. 官方來源定義不可偷換：TWSE MIS OTC 仍僅屬操作備援，不能聲稱 TPEx 官方完整即時來源。

## 驗收條件
- 單元測試確認部分有效行情仍能顯示，且所有研究觀察 trade_eligible=false。
- 真實盤中 GitHub Actions run 須證明 scanner 執行、TWSE/TPEx 分別覆蓋率、產物上傳與讀回。
- 六套模型逐一驗證真實 entrypoint、時間、信號 ID、輸出、拒絕原因及事後追蹤後，才能稱作六模型即時掃描。
- 本 PR 僅將研究可見性接上，不宣稱已完成全市場行情或六模型上線。
