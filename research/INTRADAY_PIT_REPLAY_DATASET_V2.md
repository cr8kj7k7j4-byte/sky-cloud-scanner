# Intraday PIT Replay Dataset V2 — Schema, Lineage & Handoff Contract

- Owner: W3A｜Sky Data & Feature Engineering
- Pipeline version: W3A_INTRADAY_PIT_PIPELINE_V2_0
- Production impact: NONE
- Production baseline remains: Sky Day Trading v1.4 Dynamic Capital Rotation / P0-C MVP

## Row grain

one symbol × one observation_timestamp × one candidate decision

Primary join key: decision_id

decision_id must be unique.

## Assembly order

1. Historical candidate decision stream
2. PIT universe membership
3. Market context
4. Effective-dated sector mapping / Sector RS
5. Decision-time feature context / MTF / Phase / Anti-Chase
6. Full contemporaneous candidate-pool ranking context
7. Execution context
8. Outcome join
9. Fixed 0.45% / 0.65% cost scenarios
10. Coverage / leakage / timestamp audit
11. W2 fail-closed validation runner

Outcome fields are joined only after all decision-time context has been frozen.

## Domain source contracts

### PIT Universe
Required source:
- governed historical membership interval ledger

No current-universe backward substitution is allowed.

### Market Context
Required:
- market_regime
- market_return
- market_breadth
- market_volatility

Cross-sectional equal-weight return may be retained as a diagnostic field but may not silently replace an explicit market benchmark return.

### Sector Mapping / Sector RS
Sector mapping must have:
- symbol
- exchange
- sector
- effective_from
- effective_to

Historical intervals may be reconstructed backward only from:
- a verified current sector anchor, AND
- official effective-dated old-sector → new-sector change events.

Any missing anchor, change-chain mismatch, or unverified old sector remains unresolved.

### MTF / Phase / Anti-Chase
Frozen Production-v1.4 rule outputs must be supplied or generated by a canonical frozen rule implementation.

Research-only / rejected candidate logic must never be substituted for Production-v1.4 gate outputs.

### Candidate Pool / Ranking
Must preserve the full contemporaneous eligible pool.
Winner-only or Top-N-only historical records do not satisfy the contract.

### Execution
Unknown spread, slippage, liquidity penalty, and fill evidence stay NULL/UNKNOWN.
Zero is not a missing-value substitute.

### Outcomes
Outcome joins occur after feature freeze.
Counterfactual rows must be labeled COUNTERFACTUAL.
No outcome field may be used to construct a decision-time feature.

## Cost scenarios

Primary:
- round-trip 0.45%

Stress:
- round-trip 0.65%

For the fixed W2 research stress fields:
cost drag in R = planned_entry × round_trip_rate / (planned_entry - planned_stop)

The scenario requires gross outcome R (or an outcome exit price that can deterministically produce it).

These fixed stress scenarios are not empirical spread/slippage observations.

If supplied net_r_045 / net_r_065 disagree with the deterministic scenario calculation, status = CONFLICT and the replay fails closed.

## Acceptance gate

W2 efficacy is allowed only when:
- PIT Universe >=95%
- Market Context >=95%
- Sector Mapping >=95%
- Sector RS / price >=95%
- Core Phase / Anti-Chase >=95%
- Outcomes >=95%
- net_r_045 =100%
- net_r_065 =100%
- Leakage audit = PASS
- Timestamp causality violations = 0
- OOS present
- W2 replay contract = PASS

Any failure:
DATA_BLOCKED

A data-contract PASS does not authorize Production promotion.
