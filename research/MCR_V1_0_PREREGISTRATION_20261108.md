# Sky MCR V1.0 — 融資斷頭洗盤反轉交易決策模型

**版本**: MCR-V1.0-RC1 | **首次預註冊**: 2026-11-08 | **狀態**: INSUFFICIENT_DATA / RESEARCH_ONLY | **方向**: 做多、現股當沖 | **非 Production**

## 核心可檢驗假設

以公開資訊**推估**融資維持率 <130% 的股票，在盤中先有賣壓耗盡，隨後出現具時間戳的外盤買方成交觀察與價格突破、回測支撐後，**可能**比單純低維持率反彈有更好的成本後期望值。低融資維持率本身不得視為買點，亦不等於已實際強制斷頭。

相較封存的通用開盤突破／回測策略，本候選以 **PIT 低融資維持率 + 盤中賣壓清洗 + 主動買盤轉換** 為結構性新假設；不是重新調整封存策略的門檻。若資料無法支持獨立變數與執行時間，直接 HOLD。

## 硬性條件（預註冊，禁止為了美化績效修改）

- 股票池：上市／上櫃、前一實際交易日（非日曆日前一天）FinMind `TaiwanStockMarginMaintenance` 推估維持率 **<130%**、融資餘額 **>=100 張**；股價 **<100 元**；需可現股當沖。假日、休市、缺資料、無有效維持率值 → 不交易。
- 價格行情：真實交易日台灣時間 09:10–12:45；報價延遲 <=35 秒、買賣價差 <=0.5%，排除漲跌停鎖住、低流動性或市場閘門否決。上市/上櫃完整涵蓋與行情授權待驗收。
- S1：跌深／融資壓力存在（只選股票池，不買進）。
- S2：必須有可觀測且時間一致的恐慌賣壓與賣壓減弱證據。兩個旗標 `forced_selloff_observed`、`seller_exhaustion_confirmed` 必須由獨立 PIT 資料計算，**不可手動預設為真**；定義及品質未取得時一律等待。
- S3：買盤必須有三個**不同時間**外盤快照，價格與累積成交量遞增，90 秒內價漲 >=0.7%、量增 >=10 張（PR #311 原型）。10 秒快照不代表完整逐筆連續買單。
- S4：1 分鐘相對量 >=1.3；站上 VWAP；股價有效突破事先計算的壓力價。階段僅 P3 健康回測或 P4 二次突破，市場閘門須通過。
- S5：成交價不得超過突破價 0.4%；相對前日收盤不得漲超過 7%；最近結構性回測低點為停損（距進場價 <=2%）。不可將停損往虧損方向移動。
- S6：兩個目標來自交易前已觀測的獨立壓力價，不得為了湊 RR 推高。使用 primary 0.45% 來回成本測 RR1 >=1.5；stress 0.65% 測 RR2 >=2.0；採最保守已估成本，不以實證手續費 0.2166% 替代完整成交成本。若滑價、價差與成交率未驗收，execution_cost_covered=False 直接禁交易。
- S7：P0-R：總資金 50 萬；單筆最大風險 NT$5,000；單股名目上限 NT$100,000；最多 3 檔、全組合風險 NT$15,000；日淨損 <= -NT$10,000 或連續 2 筆停損後不再開新倉。不虧損加碼，不追高，不自動下單。
- 訊號輸出僅 `禁止交易`、`等待`、`RESEARCH_READY`；最後者依然**不是正式可執行買進**。

## 待建置資料計算契約

`research/mcr_v1_decision.py` 為**純決策函式**，所有輸入都由上游 PIT 資料與驗證器提供。尚未接入 S2 賣壓衰竭、VWAP、突破價、交易資格、真實阻力位、滑價及成本覆蓋等來源；絕不得用假設 True 或人工估值產生正式訊號。觀測快照僅能證實快照當下賣買方向，不可推斷每筆逐筆成交。

`research/margin_rebound_watch.py` 仍只提供先前研究警戒（非模型正式信號），已知 API schema、Sponsor 權限和通知送達未完成驗證。原型持倉與去重狀態留存在 RAM，尚未達可靠部署條件。

## 預先固定回測設計

- 比較組：A 低維持率單因子；B 低維持率＋快照買盤；C MCR 完整結構，成本與股票池一致；並記錄不交易比例。
- 時間序列：當日已知資料才可使用；事件、公告、歷史成分股皆採 PIT。2026 已研究資料不能當作 fresh OOS。
- 執行：訊號完成後**下一個可成交報價**進場；停損使用保守跳空／滑價模型；最晚 13:20 平倉，禁止隔夜；考慮當沖交易資格、買賣單位、時間、漲跌停、流動性與交易稅。
- 指標：總樣本、實際獨立交易數、期間分布、R 倍數、MAE/MFE、成本後期望值、PF、最大回撤、容量、日內成交率、假反彈率、時間延遲、空缺欄位比例。
- Train/Validation/OOS 不混用；>=3 walk-forward folds、牛/盤/熊 regime 分析；0.45% primary 與 0.65% stress；去除單一特徵 ablation；不得事後調整 130%／0.7%／1.3 倍量／0.4% 追高否決門檻等。
- 前瞻 Shadow/Paper 最低門檻：>=200 可評估獨立樣本，>=20 **真正未來**交易日，>=2 市場環境，結果完整率>=95%，單檔集中<=20%，另需成本後正期望／合理 PF、DD、容量、成交驗證。
- 所有重大關卡通過才可提交 W0/P0-G 評審，不能由研究分支自行升級 Production。
