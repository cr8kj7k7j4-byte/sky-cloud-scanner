# W5 → W0 → W1/W2 Handoff Protocol

## 1. W5 authority
W5 僅負責：
- 新想法 Intake
- Evidence Review
- Duplicate / Low-value Gate
- Data feasibility
- PIT feasibility
- Pre-registration readiness
- Candidate archive / rejection

W5 不負責：
- Production 升版
- Champion 替換
- 實盤部署
- 覆蓋 P0-C / P0-R
- 改寫正式 Strategy Registry

## 2. Handoff package

只有 `ACCEPT_FOR_PREREGISTRATION` 可送 W0，最少包含：
1. Candidate Intake
2. Structural Difference
3. Rejected-family comparison
4. Data feasibility
5. PIT assessment
6. Fresh OOS plan
7. Pre-registration draft
8. Cost model
9. Portfolio / capacity plan
10. Main risks

## 3. W0 decision

W0 可決定：
- Reject / Hold
- 送 W1（Swing）
- 送 W2（Intraday）
- 要求 W3 補資料／基礎設施
- 要求 W5 補證據
- 排入後續研究優先序

## 4. Promotion boundary

即使 W1/W2 驗證成功，也只能成為 Shadow/Paper Candidate。
正式 Production 仍需：
PIT + leakage/survivorship + preregistration + walk-forward + OOS + cost stress + portfolio/capacity + shadow/paper + P0-R + P0-G。

## 5. No silent promotion
任何聊天視窗、Notebook、Branch、單次回測、漂亮論文或主觀信心都不得直接改 Production。
