系統限制與安全

目前版本提供 iPhone 介面、JSON 匯入、訊號檢視、成本與風險試算、手動持倉紀錄。

尚未完成：Nova API 認證、全市場即時行情、定時掃描、背景推播、策略回測／樣本外驗證、實盤訊號發布及券商下單整合。

不要將 Nova API 密碼、憑證、私鑰或 Access Token 貼到此頁。券商金鑰必須留在安全的伺服器端。

iPhone：Safari 開啟部署後的 HTTPS 網址 → 分享 → 加入主畫面，即可像 App 一樣啟動。
